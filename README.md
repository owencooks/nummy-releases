# Nummy releases

Signed and notarized builds of **Nummy**, a little macOS menu bar app that tracks how much you actually use your numpad.

**[Download the latest version](https://github.com/owencooks/nummy-releases/releases/latest)**, open the DMG and drag Nummy into Applications. Nummy needs macOS 26 or later on an Apple silicon Mac.

Once installed, Nummy checks this page once a day and lets you know when a new version is out.
